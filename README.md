SNAKE ARENA - README
====================
SnakeGame là game rắn săn mồi offline theo phong cách truyền thống.
Phiên bản hiện tại là MVP, tập trung vào core gameplay.
Phiên bản đã có UI cơ bản nhưng chưa có đồ họa
Chức năng hiện có:
+ Điều khiển rắn di chuyển 4 hướng
+ Ăn thức ăn để tăng điểm
+ Rắn dài ra sau khi ăn
+ Kiểm tra va chạm với tường, thân rắn và vật cản
+ Kết thúc game khi thua

Lưu ý:
- 5 map hiện tại chỉ là bản demo để kiểm thử gameplay
- UI hiện tại còn đơn giản, chưa có thiết kế đồ họa hoàn chỉnh
- Chưa có âm thanh, animation và high score hoàn chỉnh
